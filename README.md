# Axcel One student redesign prototype

An interactive concept for the student side of Axcel One. This is a static demonstration with fictional sample data; it is not connected to the school's systems and does not provide real sign-in.

## Preview

The public preview is published with GitHub Pages: https://imrainybeee.github.io/axcel-one-student-prototype/

## Run locally

```sh
npm ci
npm run dev
```

To build the site:

```sh
npm run build
```

The Pages build sets `VITE_BASE_PATH` to the repository's project-site path. Local builds use `/` by default.
