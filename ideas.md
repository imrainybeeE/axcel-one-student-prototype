# Ideas

## Axcel AI tutor

In the future, add a clear button in Axcel One that opens an AI tutor for students. Use the cute four-colour character as its mascot so students can recognize and return to it easily.

The tutor could help explain class topics, answer study questions, and offer practice. The prototype’s Today screen now includes a prominent visual concept card for this idea; the button opens a note explaining that the tutor is not a working feature yet.
